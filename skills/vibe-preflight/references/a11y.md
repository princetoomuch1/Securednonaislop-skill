# Accessibility rules (F-), WCAG 2.2 AA

WebAIM Million 2026 (Feb 2026 crawl): 95.9% of home pages fail WCAG 2; 56.1 errors per page; low contrast 83.9%, missing alt 53.1%, unlabelled inputs 51%, empty links 46.3%, empty buttons 30.6%, missing `lang` 13.5%. These six cause 96% of errors. A CHI 2026 study of 300 LLM-generated UIs found ~1.8 semantic violations per UI that pass automated checks. UsableNet counted 5,000+ US digital accessibility suits in 2025; overlay widgets did not prevent 1,400+ of them.

Automated tools catch part of WCAG. Always add: keyboard walk, 200%/400% zoom, reduced motion, and a short screen-reader pass (NVDA or VoiceOver) on signup and the main task.

| Rule | WCAG | Fail pattern | Fix |
| --- | --- | --- | --- |
| f-01 | 1.4.3, 1.4.11 | Grey microcopy, text on gradients/images, faint borders | 4.5:1 text, 3:1 large text and UI parts; check gradient worst stop |
| f-02 | 1.1.1, 2.4.4, 4.1.2 | Missing alt, empty links/buttons | Meaningful alt or `alt=""`; accessible names |
| f-03 | 1.3.1, 4.1.2 | `div onClick`, ARIA misuse, nested interactive | Native elements; APG patterns |
| f-04 | 2.1.1, 2.1.2 | Menus/dialogs unreachable or trapping | Tab walk; Escape closes; focus returns |
| f-05 | 2.4.7, 2.4.13 | `outline: none` with nothing instead | `:focus-visible` ring 2px, 3:1 |
| f-06 | 2.4.11 | Sticky header or cookie banner hides focus | `scroll-padding-top` |
| f-07 | 1.3.5, 3.3.2 | Placeholder as label, no `autocomplete` | `<label for>`, autocomplete tokens |
| f-08 | 3.3.1, 4.1.3 | Errors in red only; silent toasts | `aria-describedby`, `role=status`/`aria-live` |
| f-09 | 2.5.8 | Icon buttons under 24x24, unnamed | 24px minimum (44 better), `aria-label` |
| f-10 | 1.3.1, 2.4.1, 2.4.6 | No landmarks, many h1s, skipped levels | One h1, logical outline, skip link |
| f-11 | 2.3.3, 2.2.2 | Motion ignores reduced-motion; autoplay | `prefers-reduced-motion`, pause controls |
| f-12 | 1.4.4, 1.4.10 | Breaks at 200% zoom / 320 px | Fluid layout, rem units |
| f-13 | 3.1.1, 2.4.2 | No `lang`, template titles | `lang`, real titles |
| f-14 | 2.4.4 | "Click here", "Learn more" | Descriptive link text |
| f-15 | 2.5.7 | Drag-only interactions | Button alternative |
| f-16 | 3.3.8 | Paste blocked, puzzle CAPTCHAs | Allow paste/password managers, passkeys |
| f-17 | 3.2.6 | Help link moves around | Consistent placement |
| f-18 | 2.4.3 | Dialog does not take or return focus | Native `<dialog>` or Radix/Headless UI |

LLM repair works well for many of these (an arXiv 2026 study cut violations from 3.98 to 1.7 per file), so `fix` mode should handle F-02, F-05, F-07, F-09, F-13, F-14 automatically and leave contrast and structure for review.
